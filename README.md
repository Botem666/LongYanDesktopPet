# 坎特蕾拉桌宠物（PyQt6）

基于小蕾米桌宠精简而来的桌面宠物，角色替换为坎特蕾拉（鸣潮）。

## 运行

```bash
pip install -r requirements.txt
python pet.py
```

依赖：`PyQt6>=6.6`

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 移动桌宠位置 |
| 左键单击 | 随机表情互动，2 秒后恢复 |
| 左键双击 | 在默认状态与选定的「双击动作」之间切换 |
| 鼠标滚轮 | 缩放大小（0.5x ~ 2x） |
| 右键菜单 | 重置位置 / 开机自启 / 双击动作 / 退出 |

### 右键菜单

- **重置位置和大小**：恢复默认位置和缩放
- **开机自启**：勾选后 Windows 开机自动启动（写注册表 `HKCU\...\Run`）
- **双击动作**：按分类（待机/反应/拖拽/动作）自选双击时播放的 GIF
- **退出**：关闭桌宠

## 表情包分类（40 个 GIF）

| 分类 | 数量 | 触发方式 | 包含表情 |
| --- | --- | --- | --- |
| 待机 (idle) | 6 | 启动时随机 / 单击恢复 | 启动、吃薯片、喝奶茶、喝茶、纸箱等 |
| 反应 (reactions) | 17 | 单击随机触发 | 害羞、喜欢、震惊、生气、无语、慌、阴险等 |
| 拖拽 (drag) | 6 | 拖动桌宠时播放 | 抱抱、扶墙、想要、戳戳、对手指、拉泪 |
| 动作 (actions) | 11 | 双击时播放（可自选） | 点赞、鼓掌、中指、吐舌、上工等 |

## 目录结构

```
pet.py              桌宠主窗口（DesktopPet），入口文件
constants.py        常量配置（GIF 分类字典）
gif/                40 个坎特蕾拉表情 GIF
favicon.ico         程序图标
坐标配置.json        每个 GIF 的绘制偏移（默认全 0，可手动微调）
设置.json           记忆上次位置/大小/双击动作（退出时自动生成）
```

## 二次开发

1. 添加新表情：把 GIF 放入 `gif/`，然后在 `constants.py` 的 `GIF_CATEGORIES` 对应分类中加入文件名
2. 调整偏移：修改 `坐标配置.json` 中对应 GIF 的 x/y 值

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "坎特蕾拉桌宠" --icon favicon.ico \
  --add-data "gif;gif" --add-data "favicon.ico;." pet.py
```

单文件输出在 `dist/坎特蕾拉桌宠.exe`。
