# 胧嫣桌宠

尘白禁区-胧嫣，桌面宠物。

## 感谢
- 在 https://github.com/todaywish945-ux/- 的基础上二次开发
- 表情包素材来源：B站@吃个咲夜吧

## 运行

```bash
pip install -r requirements.txt
python pet.py
```

依赖：`PyQt6>=6.6`、`pynput>=1.8`

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 移动桌宠位置（松手自动吸附回屏幕内） |
| 左键单击 | 随机表情互动，2 秒后恢复（并弹出台词气泡） |
| 左键双击 | 在默认状态与选定的「双击动作」之间切换 |
| 鼠标滚轮 | 缩放大小（0.5x ~ 2x） |
| 托盘图标单击 | 隐藏 / 显示桌宠 |
| 托盘图标右键 | 打开功能菜单 |

### 托盘菜单

- **隐藏 / 显示桌宠**：从桌面收起或重新显示
- **重置位置和大小**：恢复默认位置和缩放
- **锁定位置**：勾选后禁止拖拽移动桌宠
- **边界吸附**：勾选后拖拽松手自动吸附回屏幕边缘
- **开机自启**：勾选后 Windows 开机自动启动（延迟 10 秒，避免开机抢资源）
- **随机待机**：勾选后空闲时每 20 秒随机切换一个待机表情
- **按时问候**：勾选后早（6-12）/午（12-18）/晚（18-24）固定时段各问候一次
- **打字检测**：勾选后检测到键盘输入时播放「记笔记」动画，停止约 2 秒后恢复待机
- **全屏隐藏**：勾选后前台应用全屏时自动隐藏桌宠（仅 Windows）
- **缩放步进**：勾选后滚轮缩放按固定档位（0.5x~2x），取消则为平滑缩放
- **透明度**：调整桌宠整体透明度（100% / 80% / 60% / 40%）
- **双击动作**：按分类（待机/反应/拖拽/动作/打字）自选双击时播放的 GIF
- **退出**：关闭桌宠

## 表情包分类（14 个 GIF）

| 分类 | 数量 | 触发方式 | 包含表情 |
| --- | --- | --- | --- |
| 待机 (idle) | 5 | 启动时随机 / 单击恢复 | 卖萌、吃爆米花、吃瓜、记笔记1、记笔记2 |
| 反应 (reactions) | 5 | 单击随机触发 | 哈喽、害羞、摇一摇、灵魂出窍、难绷 |
| 拖拽 (drag) | 1 | 拖动桌宠时播放 | 摇一摇 |
| 动作 (actions) | 4 | 双击时播放（可自选） | 有钱、超级有钱、来喝一杯、比心 |
| 打字 (typing) | 2 | 打字检测触发 | 记笔记1、记笔记2 |

> 部分表情跨分类共享（记笔记1/2 同时属于待机与打字、摇一摇同时属于反应与拖拽），去重后共 14 个 GIF。

## 目录结构

```
pet.py              桌宠主窗口（DesktopPet），入口文件
constants.py        常量配置（GIF 分类 + 气泡台词）
gif/                14 个胧嫣表情 GIF
favicon.ico         程序图标
坐标配置.json        每个 GIF 的绘制偏移（默认全 0，可手动微调）
设置.json           记忆上次位置/大小/双击动作/开关状态（退出时自动生成）
```

## 二次开发

1. 添加新表情：把 GIF 放入 `gif/`，然后在 `constants.py` 的 `GIF_CATEGORIES` 对应分类中加入文件名
2. 调整偏移：修改 `坐标配置.json` 中对应 GIF 的 x/y 值
3. 添加新台词：在 `constants.py` 的 `BUBBLE_LINES` 对应分类（click / greet_morning / greet_afternoon / greet_evening）中加入句子

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "胧嫣桌宠" --icon favicon.ico  --add-data "gif;gif" --add-data "favicon.ico;." pet.py
```

单文件输出在 `dist/胧嫣桌宠.exe`。
